# MedPer V2

A V2 transforma o MedPer em uma estação de trabalho médico-pericial centrada no caso. O fluxo principal é local-first e independe de backend para abrir, editar e exportar.

## Fluxo

1. Resumo
2. Objeto e contexto
3. Autos e fontes
4. Cronologia
5. História e antecedentes
6. Exame pericial
7. Método e instrumentos
8. Análise médico-pericial
9. Quesitos
10. Conclusão
11. Documento final

O sistema organiza método e evidências, mas não substitui decisão médica. Métodos contextuais são sugestões; conclusões permanecem sob controle da perita.
