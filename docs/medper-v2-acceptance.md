# MedPer V2 — critérios de aceitação

A candidata V2 só deve ser considerada pronta quando:

- abre sem backend, login ou rede previamente configurados;
- permite criar, buscar, abrir, editar e excluir conteúdo interno de casos;
- persiste casos localmente e restaura após recarregar;
- permite backup JSON e importação posterior;
- conduz o caso pelas 11 etapas do workspace;
- cadastra fontes/autos e cronologia;
- registra história e exame dirigidos;
- sugere metodologia por contexto sem decidir conclusão;
- oferece AIPE e POSAS quando dano estético/cicatricial é pertinente;
- registra matriz de evidências e quesitos;
- registra conclusão exclusivamente por ação da perita;
- gera documento final A4 imprimível com o conteúdo do caso;
- mantém suíte legada e regressões V2 integradas ao `npm run audit`;
- não reintroduz dependência obrigatória de API remota.
